# 山河织路 · 制作与素材

五座场景的三维地形、街巷、桥梁和发射设施采用本项目的 Blender 场景。人力车、县城轿车和火箭来自本项目。街道摊位、弧顶温室、人物和植被的空间布置、分阶着色、镜头、交互及配乐在本项目中完成。

手绘动画风格的天幕、店铺与墙面、人物、地表和树群采用图像生成工具辅助制作。十二张原始绘景保存在 `assets/sources/painted`。其中六张用于天空或远景，六张图集切为二十四个局部纹理。人物采用带透明轮廓的二维绘像，种植与房屋构件在三维空间中定位。

第三幕的机车及绿皮客车、第四幕的和谐号与复兴号沿用作者提供的本机「AI绘廉／轨上清风」项目。保留原模型轮廓、车体涂装和字标，重新编组并压缩：绿皮机车后接十六节客车，复兴号、和谐号各由两端头车与十节中间车组成。重复车厢共享网格与材质。原文件及校验值保存在 `assets/sources/guishangqingfeng`。此处记录来源与改编范围，列车原项目的第三方素材应随原作者的授权说明使用。

第一幕底模保留 Poly Haven 提供的土路、木材、灰泥、布料及瓦面材质，实时着色叠加绘制的地表、墙皮和瓦纹。原文件与校验值见 `assets/materials/polyhaven/manifest.json`。[Poly Haven 许可](https://polyhaven.com/license)

县城影院的《秋信》《桥上春风》《山月行》为作品内虚构的影片。海报画面和夜城的六格窗内景使用图像生成工具辅助绘制，原图保存在 `assets/sources/scene-print`，排字和用于三维模型的图集保存在工程中。

题字和木匾使用马善政毛笔楷书，商铺及站名使用站酷庆科黄油体。主标题嵌入字形子集，近景字牌按原字形制成立体网格，两种字库均按 SIL Open Font License 1.1 使用。字体来源、版本与许可原文随工程与参赛包保存。[马善政毛笔楷书](https://github.com/google/fonts/tree/main/ofl/mashanzheng) · [站酷庆科黄油体](https://github.com/google/fonts/tree/main/ofl/zcoolqingkehuangyou)

第二至五幕的十二种树模选自 Quaternius《Stylized Nature MegaKit》免费标准版，依据 CC0 1.0 Public Domain Dedication 使用。保留源网格、树皮和叶片轮廓，重新处理实时面数、叶色与法线，分场景栽植。第一幕沿用原田埂绘景。随包保留原许可。[作者页面](https://quaternius.com/packs/stylizednaturemegakit.html) · [作者在 OpenGameArt 发布的标准版](https://opengameart.org/content/stylized-nature-megakit)

网页使用 Three.js、Meshopt 和 WebGL 2。展板和影片画面从交付版本的实时程序采集，操作控件和长文采用系统字体。
