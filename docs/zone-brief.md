# 《山河织路》场景制作规范（内部）

> 历史制作简报。当前场景的建模、渲染、授权与验收以[交付版美术规范](美术规范与验收.md)为准。

作品：2026 华灿奖 · 创意赛道 · 数字媒体设计
形态：可漫游实时 3D 数字长卷 H5（PC / 移动端）
美术：东方纸艺立体长卷。五座 320×300m 悬浮“岛”，纸白虚空，一根红线缝合。场景为“手作纸模型”质感：大量构造细节、平面化配色、顶点色微差、纸纹/墨线后期。禁止粗陋几何体拼人；不要人物；用载具、门窗、灯火、晾晒、招牌等生活痕迹叙事。

## 技术与文件约定

- Blender 4.2：`D:/Blender/blender-4.2.9-windows-x64/blender.exe -b --factory-startup --python <script>`
- 建模库：`tools/blib.py`（只读，不要修改）。参考实现：`tools/build_rural.py`（只读）。如需新构件，写在自己的脚本里。
- 材质：`B.vmat()` 顶点色；自发光用 `B.mat(..., emission=..., emis_strength=...)`；招牌用 `B.mat(texture=assets/signs_atlas.png)`；水对象必须命名为 `Water_*`，材质名 `Water`（运行时替换为水面 shader）。
- 所有静态几何按材质合并：`B.join_materials("<Zone>", ALL)`；保留 `Water_*` 与 `FX_*` 空物体。
- 岛屿：`B.ground_slab` + `B.terrain`，底座 320×300×9，顶面 z=0。道路/建筑/道具放在岛内。岛外沿可留山体/纸白。
- 导出：`assets/zones/<zone>.glb`，`.blend` 同目录；载具 `assets/vehicles/<vehicle>.glb`，原点在地面中心，车头朝 Blender +Y，Z 向上。
- 坐标：Blender X 横向，Y 纵深（+Y = 时间前进方向），Z 上。Three.js 中 X→X，Y→-Z，Z→Y。
- 空物体：`FX_Hotspot`（拾光点）、`FX_Smoke_1...`（烟/蒸汽）、`FX_Light_*`（灯位）等，命名清楚。
- 预算：每岛 120k–260k 三角面；GLB < 18MB。宁可细节多、合并好，不要大量 draw call。
- 原创：不得下载外部模型/贴图/图片；招牌只能使用现有 atlas 的 key（见下）；所有文字、品牌、场景均为虚构原创。不要出现真实人物、真实机构名、真实品牌。
- 视角：H5 会以 35–50mm 电影镜头在岛内穿行 + 高空俯瞰。街道尺度 1 单位=1m。重要近景（载具/招牌/门窗）要经得起 3–5m 观看。
- 色彩：用低饱和但有对比的纸色；H5 会打光。不要做照片写实；不做玩具低多边形。

# 1. 城镇岛（1990s 县城黄昏）— 指派

- 8–10 米宽主街沿 Y 从 -140 到 +140，轻微 S 弯；两侧人行道、路缘、电线杆、路灯、斑马线、井盖。
- 25–30 栋 2–4 层临街建筑：砖混/白瓷砖/水泥，底层商铺、卷帘门/玻璃、雨棚、招牌；上层窗户、阳台、晾衣、空调外机、水塔、电视天线、女儿墙；少量坡屋顶。
- 关键建筑：春风百货、时光照相馆、人民理发店、长路书店、山河饭店、供销社、电影院（带雨棚和海报墙）、旅社、汽车站（班车+站牌）。
- 一条运河/河涌横穿（Water_Canal），石砌驳岸、柳树、石拱桥、小船。
- 街市：摊位、竹筐、木箱、塑料棚、冰棍箱、菜摊、自行车、三轮车、长椅、邮筒、消防栓、公共水龙头、红色横幅（无字色块）、张贴海报。
- 远景：低层住宅、烟囱、水塔、树；岛边低山。
- 载具：一辆 1990s 方盒子轿车（car.glb）作为主角，放在街心偏侧；另可做一辆停靠的班车/三轮车（静态）。
- 色调：琥珀黄昏、砖红、青灰、暖黄窗光、少量霓虹初亮。
- 光照由 H5 处理；岛内可加自发光灯罩/窗。
- FX：`FX_Hotspot` 在轿车旁；`FX_Smoke_1` 在饮食摊；街道灯位若干。

# 2. 高铁岛（2020s 山河黎明）— 指派

- 320×300 的深切河谷：一条大江从岛中穿过，两侧层叠山体（纸艺层山）、梯田、树林、远处小村。
- 一座大跨度斜拉桥沿 Y 跨越河谷（桥面 z≈32，跨度约 220m），两座 A 形桥塔（高 70–80m）、斜拉索、护栏、检修道、轨道、接触网杆与线；桥塔基础在水/岸。
- 一列白色高速动车组（hsr.glb）跨桥；车头流线型，6 节，车长 25m/节，宽 3.3、高 3.9；车窗深色带、红色/蓝色细腰线、受电弓、转向架、车间连接。原点在车底中心，车头朝 +Y。
- 其他：风车/光伏、江面小船、飞鸟（可空物体/H5 粒子）、岸边小站“云岭站”站牌、桥名“山河大桥”。
- 色调：黎明粉金 + 钢蓝山脊 + 青绿江水；H5 打光。
- FX：`FX_Hotspot` 在桥塔/车窗附近；`FX_Smoke` 不需要。

# 3. 未来岛（2035+ 星河港）— 指派

- 320×300 的未来山地/海滨生态城：12–18 座白色曲面高层，水平绿色露台、空中连桥、发光缝；磁浮环线/轻轨；太阳能阵列、风机、雨水花园、水面。
- 一座航天发射场：重型运载火箭（rocket.glb，3 助推 + 芯级，高约 60m，原点在底部，竖直 +Z）、发射塔、避雷塔、燃料罐、导流槽、探照灯、场坪；“星河港”标识。
- 道路/光轨从城市通向发射场，作为“红线”的终点。
- 色调：靛蓝、极光青、白色曲面、金色尾焰；岛内自发光窗/缝。
- FX：`FX_Hotspot` 在火箭旁；`FX_Smoke_1` 在火箭底部（H5 发射时用）。
- 火箭模型单独导出，细节：芯级/助推器、喷管、栅格舵、整流罩、管路、级间段、支撑臂；不要贴真实国旗/机构标识。

# 4. 城市岛（2010s 雨夜）— 主控自建（不需要指派）

- 30–40 座塔楼、高架、绿皮火车、霓虹、雨夜、河流、工地。由主控完成，其他 agent 不要动城市文件。

# 5. 车辆模型规范

- `car.glb`：90 年代方盒轿车，车长约 4.4m，宽 1.7，高 1.5；车头 +Y，原点地面中心。细节：车顶/引擎盖/后备箱折面、车窗、镀铬保险杠、格栅、方灯、轮毂、后视镜、门缝、天线、车牌空白。颜色深酒红/白；单独导出。可作为出租/公务车，无品牌。
- `hsr.glb`：6 节编组，总长约 150m；细节见上；车头流线用截面放样（blib.loft）。
- `rocket.glb`：见上；用 lathe/loft/cylinder 组合，喷管用旋转剖面；细节。
- 所有车辆：单独 GLB，部件按材质合并但保留轮/车窗等可识别对象；三角面 20k–120k；不要人物。

## 评审标准（自检）

1. 3 米内看：门窗/瓦/招牌/栏杆/管线有真实构造，不是几个盒子。
2. 30 米看：天际线/街廓/桥/山体有节奏，有生活痕迹。
3. 纸艺风格统一：平面色块 + 顶点色微差 + 墨线；不要照片贴图。
4. 没有真实品牌/人物/外部资产。
5. GLB 能加载，UV/材质/顶点色正确，水/FX 命名正确。
