# 《山河织路》概念锁定稿

> 赛道：2026 新锐设计竞赛·华灿奖 / 创意赛道 / 数字媒体设计
> 竞赛主题：融·合
> 形态：可漫游的实时 3D 数字长卷（H5，PC + 移动端）
> 一句话：一条路，把五段中国时间织在一起。

## 1. 核心概念

中国的发展，常常被写成宏大的数字。但数字之外，它更像一条路：从田埂出发，穿过街市、城市与山河，最后通向星河。路不是背景，路是针脚——它把乡土与城市、旧日与未来、人与土地缝在一起。

作品把“路”抽成一根贯穿全篇的红线，也把五个时代做成五座悬浮的立体微缩景观。观众不是在看一张时间轴，而是在一根线上行走：从一座岛走进另一座岛，在纸白的虚空里看见红线把时代缝合。走到尽头，可以点亮一枚火箭，为未来放一盏灯。

“融·合”在这里有四层：
- 时间的融合：五个时代由一条连续的路缝合，转场是“织过去”，不是“切过去”。
- 空间的融合：田埂、街市、都市、山河、太空并置成一轴立体长卷。
- 技术的融合：Blender 程序化建模 + WebGL 实时渲染 + 程序合成声音，全部原创。
- 情感的融合：每个时代都有一件载具和一句“路上的人话”，宏大叙事落回可触摸的日常。

## 2. 五幕结构

| 幕 | 年代 | 场景 | 载具 | 一句话 |
|---|---|---|---|---|
| 壹 · 田埂晨 | 1980s | 梯田、白墙黛瓦、晒谷场、晨雾 | 人力车 | 路是走出来的。 |
| 贰 · 街市暮 | 1990s | 县城主街、供销社、电影院、河边 | 汽车 | 路通向更大的世界。 |
| 叁 · 城夜雨 | 2010s | 高楼、霓虹、高架、绿皮车穿城 | 绿皮火车 | 路把远方变成日常。 |
| 肆 · 山河速 | 2020s | 大跨度斜拉桥、动车组、云海群山 | 高速动车 | 路让山河彼此相拥。 |
| 伍 · 星河远 | 未来 | 零碳山城、发射场、极光、星海 | 重型火箭 | 路从脚下，通向星辰。 |

结尾：镜头从发射场拉升，五座岛在纸白虚空中连成一根发光的红线，像一轴被完全展开的长卷。字幕：**所有远方，都从脚下出发。**

## 3. 视觉系统

- **东方微缩立体长卷**：五座 320m 见方的“岛屿”各自有地形、建筑、植被、人物痕迹；岛体有土壤剖面，像博物馆里的地形模型。
- **红线母题**：路在场景中是土路/柏油/钢轨/光轨；在转场与总览中变成一根发光的中国红丝线，是“织”的具象。
- **纸白虚空**：岛与岛之间不是黑场，而是温暖纸白的“留白”。转场时镜头升到高空，看见上一座岛、下一座岛与中间的红线，再落回人间。
- **材质**：不做写实照片感，也不做低幼低多边形。用大量真实构造细节（瓦垄、窗棂、阳台、空调机、电线、桥梁拉索、火箭发动机）+ 克制的低饱和配色 + 纸纹颗粒 + 轻雾，形成“手作模型”的质感。
- **色彩**：
  - 乡土：米白、黛瓦、秧绿、土黄、朱红点缀。
  - 城镇：琥珀、砖红、青灰、初亮的暖黄窗光。
  - 城市：深蓝、湿沥青、青蓝玻璃、霓虹洋红/青、万家灯火。
  - 高铁：黎明粉金、钢蓝山脊、银白列车、青绿江水。
  - 未来：靛蓝、极光青、白色曲面建筑、金色尾焰。
- **镜头**：低机位穿行与高空俯瞰交替；35–50mm 电影感焦距；轻微手持呼吸感；关键节点停一拍。
- **字体**：思源宋体（SIL OFL）子集，标题横细竖粗，正文克制；印章式章节标记“壹贰叁肆伍”。

## 4. 交互系统

1. **启程**：落在乡村岛上空，红线从画面里穿出。点击“启程”，镜头俯冲入田埂。
2. **漫游**：滚轮/触摸上滑前进，下滑回望；鼠标移动产生轻微视差；到达章节时标题与年份淡入。
3. **拾光**：每一幕有一个不打扰的“拾光点”（人力车、汽车、车窗、桥塔、火箭），点击展开一张纸卡，读一句那个时代的“路上的人话”。
4. **总览**：右上角“展卷”把镜头拉到纸白虚空，五座岛与红线尽收眼底；点击任一岛可飞回该幕。这是“立体长卷”的完整形态。
5. **为未来放灯**：在终点，输入或选择一句愿望，点亮火箭；火箭升空，孔明灯与星屑一起升起，愿望以纸上小字随灯飘远。
6. **声音**：五段可循环的时代氛围音乐随章节交叉淡化；风声、车铃、火车、火箭等音效由程序合成。默认静音，启程后开启，可随时关闭。
7. **可及性**：键盘方向键/空格可漫游，Esc 退出总览；支持减少动态偏好；低性能设备自动降级（关闭泛光、降低阴影与粒子）。

## 5. 技术方案

- **建模**：Blender 4.2 Python 程序化建模。自建构件库（瓦屋顶、窗棂、阳台、空调、电线、桁架、斜拉索、火箭喷管等），按材质合并，导出 glTF。
- **场景**：五座岛独立 GLB，置于同一条世界轴线上；每座岛 320×300m，间隔 120m 纸白虚空。
- **实时**：Three.js r169。连续相机曲线 + 章节时间轴；天空/雾/光照随章节插值；自定义水面、雨、烟、星、孔明灯；Bloom + 纸纹/暗角/调色后期。
- **转场**：卷轴式“升空—看见红线—落回”的空间转场，配合纸白雾与印章动画；章节跳转使用水墨遮罩。
- **资产**：全部几何、贴图（招牌文字图集）、声音均由本项目脚本生成；不使用任何外部模型、图片或音乐。字体使用 SIL OFL 授权的思源宋体子集。
- **性能**：桌面 1080p 60fps 目标；移动端 DPR 上限 1.5、低质量档关闭 Bloom、阴影 1024、隐藏微小构件；首屏预加载 + 进度。
- **离线**：提供单文件离线版（几何/音频/字体内嵌），双击即可观看；同时提供在线版。

## 7. 评审记忆点

1. 不是“时间轴动画”，而是可以走进去的立体长卷。
2. 五座岛 + 纸白虚空 + 一根红线，形成强烈而统一的空间识别。
3. 大量真实构造细节撑起“手作模型”的可信度，而非几何体拼接的玩具感。
4. 结尾把宏大叙事收束为一次个人动作：为未来放一盏灯。
5. 全流程原创：模型、贴图、声音、交互、影像均由本项目生成。
