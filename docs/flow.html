MEMORY镜头放慢，中央浮起书脊，封面翻开。工具栏“家书”可回翻。点“留到终点回信”选中或取消。

RETURNEsc 或“返回路线”退出步行，回到编排好的镜头。

MAP点击“展卷”，在同一视图中看到五座岛。
ISLAND点岛标签，直接从目标岛的远景推入街面。
BACKEsc 或“回到路上”返回此前界面。

漫游中的其他动作

AUTO自动漫游在来信处等候，合书后续行。手动输入可暂停。
JUMP点击时间轴标记，沿原路线前往该幕。Home 返回开头，End 前往终点。
SOUND点击声音按钮或按 M 切换。音量状态随本机偏好恢复。
回信与发射节点主路线可随时合书，自由步行、展卷或回翻。未选信时，终点摊开女儿的留言。

回到路上

收起家信后可以在原地继续。展卷返回会恢复进入时的界面，选择岛标签才会改变目标章节。

键盘↑ / ↓ 或 PageUp / PageDown 控制前后，空格前进，Esc 关闭纸卡或退出展卷。弹层内 Tab 循环并在关闭时归还焦点。
触屏长滑临近来信时缓缓收住，书页展开，合书后继续。横拖转向，步行时使用屏上方向键。
显示与运动移动低画质像素比上限 1.5，阴影贴图 1024，关闭泛光。开启系统减少动态后缩短跳转，收束发射镜头。
本机存储已拾取的章节和声音偏好保存在本机。回信草稿仅保留在本次行程，重新启程时清空。
运行方式PC 与移动浏览器使用 WebGL 2。桌面可双击离线 HTML。第一次打开时静音，点击声音按钮后开始播放。
检验入口

回归从封面按钮、键盘、触控和离线文件分别进入。另测总览返回、留白与跳过、重复发射与加载失败恢复。
