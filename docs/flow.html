漫游分支 / TRAVEL

SCROLL滚轮或上滑 → 前进；下滑 → 回望；进度条同步。
DRAG按住拖动 → 改变视线；松手回正；不改变进度。
KEYS↑ / ↓ / 空格 → 前进后退；Home / End → 首尾。
JUMP点击时间轴章节 → 水墨遮罩 + 1.25s 飞行。

展卷分支 / OVERVIEW

ENTER右上角“展卷” → 镜头升空；HUD 隐去。
ISLAND点击任一岛标签 → 飞回该幕；恢复 HUD。
EXITEsc / “回到路上” → 回到进入前的位置。
THREAD总览中的红线是真实的路：五岛共享同一根曲线。

尾声分支 / FINALE

WISH输入 ≤24 字，或使用默认“愿山河无恙，路远必达”。
SKIP“直接看结局” → 跳过升空，进入尾声。
AGAIN“再看一遍” → 回到启程，重置载具与状态。
SCROLL“展开长卷” → 尾声后再次进入总览。

关键不变量

无论从哪条路径返回，进度、章节与声音必须一致：总览只改变镜头，不改变进度；章节跳转由同一条缓动曲线完成；尾声“展开长卷”回到总览，而不是重置故事。

输入映射滚轮 / 触摸上滑：前进 · 触摸下滑：回望 · 按住拖动：视线 · 点击拾光：纸卡 · Esc：退出展卷 · ← → / ↑ ↓ / 空格：键盘漫游 · Enter：启程。
移动端DPR 上限 1.5；关闭泛光、阴影 1024；卡片自适应屏宽；触摸目标 ≥ 44px；横竖屏均可用。
可及性所有按钮可聚焦；Esc 退出模态；尊重 prefers-reduced-motion：界面过渡与动画减弱，3D 漫游保留；声音默认开启但可一键静音；正文使用系统宋体回退。
性能预算在线首包约 12MB（5 岛 + 5 载具 + 纹理）；桌面 1080p 60fps 目标；移动端自动降级；加载失败显示纸白错误页并可重试。
离线单文件 HTML 内嵌全部 GLB / 贴图 / 字体回退；双击打开，无需服务器；WebAudio 在首次点击后启动（浏览器自动播放策略）。
状态持久化不写入账号或云端；仅保留当前会话的进度、声音开关与愿望文本；“再看一遍”清空会话状态。
设计取舍

不做自由第一人称：观众只需要“向前”，不需要迷路。镜头是编排好的，但速度与停留由观众决定；总览是唯一的“上帝视角”，让五段时间第一次同时出现。
